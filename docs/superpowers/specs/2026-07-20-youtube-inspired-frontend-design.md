# “视界”YouTube 风格前端改版设计

## 目标

将现有 Vue 3 视频分享前端重新设计为以 YouTube 桌面版信息架构为基础、具有“视界”原创品牌特征的视频网站。改版覆盖全部前端页面，统一使用中文，默认启用深色主题，并允许用户切换到浅色主题。

本次改版不修改后端接口，不新增需要服务器持久化的数据能力，重点提升桌面端的信息组织、视觉一致性和浏览效率。

## 范围

改版覆盖以下路由与页面：

- `/`：首页视频内容流
- `/videos`：全部视频列表
- `/video/:id`：视频播放页
- `/upload`：视频上传页
- `/dashboard`：用户中心
- `/login`：登录页
- `/register`：注册页
- `/about`：品牌说明页

本次只针对桌面宽度进行完整设计。较窄窗口需要保持内容可访问且布局不崩溃，但不提供专门的移动端导航与交互方案。

## 设计方向

采用“YouTube 框架 + 原创品牌化”方案：沿用顶部固定导航、可折叠侧边栏、分类标签、视频卡片内容流和播放页双栏布局，同时使用原创“视界”名称、红色播放图标、红橙渐变、渐变描边和柔和悬浮效果建立品牌差异。不得直接复制 YouTube 商标或品牌名称。

## 视觉系统

### 主题

- 首次访问默认使用深色主题。
- 深色主题以炭黑为页面背景、深灰为内容层级背景。
- 浅色主题使用暖白页面背景与浅灰内容层级背景。
- 主题通过 CSS 自定义属性实现，用户选择写入 `localStorage`，刷新后保持。

### 品牌与强调色

- 主色为视频红，用于 Logo、主要按钮、选中状态和重要反馈。
- 红橙渐变只用于少量品牌强调区域，避免大面积高饱和色影响观看。
- Logo 使用原创红色播放图形与“视界”文字组合。

### 布局与质感

- 顶部导航固定，内容在其下方滚动。
- 侧边导航固定并支持展开、收起；主内容宽度随侧栏状态变化。
- 视频内容流默认采用四列网格。
- 缩略图统一为 16:9，圆角适中。
- 信息密度接近 YouTube 桌面版，卡片不使用厚重边框；悬浮时显示轻微抬升、渐变描边或播放提示。
- 全站使用一致的间距、圆角、表单、按钮、空状态和加载状态。

## 全局页面骨架

### 顶部导航

顶部导航包含：

- 侧边栏展开或收起按钮
- “视界”品牌标识
- 居中搜索框、搜索按钮
- 主题切换按钮
- 上传入口
- 登录入口或已登录用户头像

搜索框在支持内容筛选的页面上执行前端搜索。其他页面仍保留统一外观，提交搜索时导航到视频列表页并带入搜索词。

### 侧边导航

侧边栏根据登录状态显示可用入口：

- 首页
- 全部视频
- 上传视频
- 用户中心
- 关于视界
- 登录与注册，或已登录用户区域

当前路由使用品牌色浅背景高亮。侧栏状态写入 `localStorage`，刷新后保持。

### 分类栏

首页和视频列表页在内容区顶部显示横向分类标签。“全部”始终可用，其余标签通过视频标题和简介关键词进行前端匹配。当前后端没有分类字段，因此不得把关键词匹配描述为服务端分类。

## 公共组件边界

- `AppHeader`：品牌、搜索、主题切换、上传入口和用户入口。
- `AppSidebar`：路由导航、登录状态呈现和折叠模式。
- `CategoryChips`：分类选择与选中态，不负责获取视频。
- `VideoCard`：标准视频卡片，只接收视频数据并触发导航。
- `VideoListItem`：播放页右侧的紧凑推荐条目。
- `LoadingState`：视频列表和页面数据加载反馈。
- `EmptyState`：无内容或无筛选结果反馈。
- `ErrorState`：中文错误信息与重试操作。
- `ThemeToggle`：切换主题并持久化用户选择。

页面负责数据请求和组合组件；公共组件不直接依赖具体 API，以便独立理解和测试。

## 页面设计

### 首页与视频列表

首页作为主要视频发现入口，视频列表页作为“全部视频”入口。两者共享视频内容流组件与筛选逻辑，页面标题和默认筛选状态可不同。

视频卡片包含：

- 16:9 缩略图
- 可用时显示视频时长；后端未提供时长时不显示虚假值
- 作者头像占位图
- 视频标题
- 作者名
- 播放量；字段缺失时使用中性占位文案
- 发布时间；字段缺失时不虚构日期

点击缩略图或标题进入播放页。加载时显示骨架屏，请求失败时显示重试按钮，无视频时显示上传引导。

### 视频播放页

页面采用左右双栏：

- 左栏为视频播放器、标题、播放信息、操作按钮、作者信息和简介。
- 右栏为紧凑的推荐视频列表。

播放页先请求当前视频，再请求视频列表作为相关推荐，并排除当前视频。后端没有点赞、收藏、订阅和推荐接口，因此相关按钮只提供本地选中反馈，界面需要避免暗示操作已经同步到服务器。

视频或推荐列表加载失败时分别显示局部错误反馈，单个区域失败不阻止其他可用内容呈现。

### 上传页

采用创作者工作室风格的双栏编辑区域：

- 左侧选择视频文件、选择缩略图并显示预览。
- 右侧填写标题和简介，显示格式提示与提交按钮。

保留现有 `/api/videos/upload` 请求、`title`、`description`、`file` 和可选 `thumbnail` 字段。上传成功后清空表单并提供进入视频列表的操作；上传失败显示后端错误信息的中文友好包装。

### 用户中心

采用频道主页式结构，显示头像占位图、用户名、邮箱、上传入口、视频浏览入口和退出登录按钮。用户数据继续读取现有登录缓存；不存在有效用户时由现有路由守卫跳转登录。

### 登录与注册

使用统一的居中品牌面板：左侧为“视界”品牌介绍和视觉装饰，右侧为表单。保留现有字段、长度限制、API 请求、认证存储和登录后重定向逻辑。所有标签、按钮和错误提示改为中文。

### 关于页

展示“视界”的产品定位、核心能力和技术说明，移除默认 Vue 示例内容。该页面不新增动态数据依赖。

## 数据流与状态

- 视频数据继续来自 `GET /api/videos`。
- 单个视频继续来自 `GET /api/videos/:id`。
- 上传、登录、注册和用户信息请求继续使用现有服务层。
- 搜索根据视频标题、简介和作者名在浏览器内过滤。
- 分类根据标题和简介关键词在浏览器内过滤。
- 搜索与分类组合时采用交集逻辑。
- 主题和侧栏状态分别持久化到 `localStorage`。
- 页面间共享的搜索词通过路由查询参数传递，使顶部搜索可以从任意页面导航到视频列表。

## 异常与边界情况

- API 请求期间必须提供可见的加载反馈。
- 请求失败必须显示中文错误面板和“重新加载”操作。
- 空视频列表与筛选无结果使用不同文案。
- 缩略图缺失或加载失败时显示本地生成的品牌占位样式，避免依赖外部占位图服务。
- 作者、播放量、发布时间或时长字段缺失时不得伪造真实数据。
- 主题初始化应在首屏渲染前尽早应用，减少明暗主题闪烁。
- 未登录用户访问受保护路由时继续使用现有路由守卫。

## 可访问性

- 图标按钮提供中文 `aria-label` 和可见的键盘焦点样式。
- 搜索、表单和上传控件使用明确标签。
- 深浅主题均满足文本和交互控件的可辨识对比度。
- 不仅依赖颜色表达选中、错误或成功状态。
- 所有主要操作可通过键盘完成。

## 验证方案

### 构建验证

- 执行前端生产构建，确保 Vue 模板、样式和依赖编译成功。

### 功能验证

- 检查全部路由可正常渲染。
- 检查深色默认主题、浅色切换和刷新后状态保持。
- 检查侧栏展开、收起和刷新后状态保持。
- 检查顶部搜索、清空搜索、分类筛选及组合筛选。
- 检查视频卡片进入播放页与推荐视频跳转。
- 检查登录状态下导航入口与退出行为。
- 检查上传表单仍提交原有字段。

### 数据兼容验证

- 使用现有后端返回字段验证视频列表与播放页。
- 使用缺失缩略图、作者附加信息、播放量或时间字段的数据验证降级展示。
- 确认新增界面交互不发出后端尚未支持的点赞、收藏、订阅或分类请求。

## 非目标

- 不修改 Spring Boot 后端。
- 不新增点赞、收藏、订阅、评论或服务端推荐接口。
- 不实现真正的服务端搜索和分类。
- 不进行移动端专项设计。
- 不直接复制 YouTube 名称、商标或品牌资产。
