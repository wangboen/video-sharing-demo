# 视频上传大小限制设计

## 目标

将视频文件上传上限从 32MB 提高到 512MB，同时保持封面文件上限为 32MB。

## 范围

本次修改覆盖所有会拦截上传大小的层级：

- Nginx 请求体限制
- Spring multipart 单文件及请求总大小限制
- 服务端媒体内容流校验
- 对应的错误信息与自动化测试

不修改允许上传的媒体格式、内容安全扫描、存储目录或审核流程。

## 方案

媒体内容校验按文件用途设置独立上限：

- 视频：512MB
- 封面：32MB

传输层配置如下：

- `spring.servlet.multipart.max-file-size=512MB`
- `spring.servlet.multipart.max-request-size=545MB`
- `client_max_body_size 545m`

请求总上限设置为 545MB，以容纳一个最大 512MB 的视频、一个最大 32MB 的封面以及 multipart 编码元数据。应用层仍分别校验视频和封面，因此提高请求总上限不会放宽封面限制。

## 数据流与错误处理

请求首先通过 Nginx 和 Spring multipart 总量校验。进入媒体校验器后，根据媒体类型选择对应大小上限，并在流式复制或审核前检查时拒绝超限文件。

视频超过 512MB 时返回明确的 512MB 限制错误；封面超过 32MB 时继续返回 32MB 限制错误。临时文件清理逻辑保持不变。

## 测试

自动化测试覆盖：

- 视频大小上限常量和超限错误为 512MB
- 封面大小上限仍为 32MB
- Spring 单文件限制为 512MB
- Spring 请求总限制与 Nginx 请求体限制均为 545MB

测试应避免在内存或磁盘中创建真实的 512MB 文件；通过边界输入流或配置契约断言验证限制。
